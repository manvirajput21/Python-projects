# 🐍 Python Projects Collection

A collection of four beginner-friendly Python projects developed to practice **Python programming, Object-Oriented Programming (OOP), classes, objects, functions, loops, conditional statements, and data management**.

These projects are menu-driven, console-based applications designed to demonstrate how Python can be used to solve common real-world problems.

## 📚 Projects Included

### 1. 🏦 Bank Management System

A simple banking application that manages account information and basic banking operations.

**Features**
- Store account holder details.
- Display account information.
- Check the current account balance.
- Deposit money into an account.
- Withdraw money from an account.
- Manage account operations through a menu-driven interface.

**Concepts Used**
- Classes and objects
- Constructors (`__init__`)
- Instance attributes
- Functions and conditional statements
- User input and arithmetic operations

**Run the project**
```bash
python3 "#Bank-Management.py"
```

---

### 2. 💼 Employee Payroll System

A payroll management application designed to maintain employee information and calculate salaries.

**Features**
- Add employee details.
- Display employee information.
- Calculate net salary using basic salary, allowances, and deductions.
- Maintain salary-related information and history.
- Perform payroll operations through a menu-driven interface.

**Salary Calculation**

Net Salary = Basic Salary + Allowances − Deductions

**Concepts Used**
- Classes and objects
- Constructors and instance variables
- Functions and methods
- Arithmetic operations
- Lists and data management

**Run the project**
```bash
python3 "#Employee-payroll.py"
```

---

### 3. 🎓 Student Management System — Project 01

A student record management application that stores student details and performs common academic record operations.

**Features**
- Add a new student.
- Display all student records.
- Search for a student using their roll number.
- Update student names and marks.
- Delete student records.
- Calculate the average marks of available students.
- Handle cases where a student is not found or no student records are available.

**Student Information**
- Student Name
- Roll Number
- Marks

**Concepts Used**
- Classes and objects
- Constructors and instance attributes
- Lists
- Functions and loops
- Searching and updating records
- Average calculation

**Run the project**
```bash
python3 "#Student-management.py"
```

### 4. 📖 Library Management System — Project 02

A library management application designed to organize book records and perform basic library operations.

**Features**

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

Verify your installation using:

```bash
python3 --version
```

### Installation and Execution

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or Terminal.
3. Choose the Python project you want to run.
4. Execute its corresponding command from the sections above.
5. Follow the on-screen menu and enter the requested information.
